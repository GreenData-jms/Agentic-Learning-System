# 05 — Assessment & Band Advancement

Advance by **demonstrated competence**, not time. Check every box in a band — across all three threads — before moving up.

---

## → Advance to Mate · Intermediate

**Mindset**
- [ ] I read and understand every suggestion before accepting it.
- [ ] I can name a class of task I would write myself rather than delegate.

**Toolset**
- [ ] I use inline completions fluently (accept, dismiss, cycle).
- [ ] I can open chat and ask a grounded question about the open file.

**Skillset**
- [ ] I shipped one real, tested result via *comment → draft → verify*.
- [ ] I rejected at least one plausible-but-wrong suggestion and explained why.

---

## → Advance to Mate · Advanced

**Mindset**
- [ ] My verification effort scales with the code's stakes.
- [ ] I can state when *not* to use Copilot.

**Toolset**
- [ ] I choose Ask / Edit / Agent correctly without thinking.
- [ ] I steer context with `#`-references and use slash commands (`/tests`, `/fix`, `/explain`).

**Skillset**
- [ ] I apply the prompting patterns (stage-set, be specific, give examples, decompose).
- [ ] I complete a normal day's task predominantly through Copilot, correctly.

---

## → Mate · Advanced complete (Mate rank achieved)

**Mindset**
- [ ] I treat generated code as untrusted input and review it for security.
- [ ] I understand and can configure content exclusion and my org's review/licensing posture.

**Toolset**
- [ ] I maintain a `.github/copilot-instructions.md` and at least one `*.prompt.md`.
- [ ] I have used Copilot code review and the coding agent, and know their limits.
- [ ] I understand MCP and have connected at least one source (or can explain why not).

**Skillset**
- [ ] I built a reusable, customized workflow others can adopt.
- [ ] I mentored one person to Beginner.

**When every box is checked, the learner holds the Mate rank for GitHub Copilot.**
