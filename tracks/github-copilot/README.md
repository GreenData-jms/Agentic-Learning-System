# Track 1 — GitHub Copilot

**Family:** GitHub · **Surface:** the IDE (VS Code / Visual Studio / JetBrains) + CLI · **Grounded in:** your code · **Rank:** Mate

This is the developer's coding assistant: code completions, chat, edits across files, and agent mode — all inside the editor, grounded in the repository you are working in. This track takes a technical beginner from first install to a fluent, safe, workflow-automating power user, bounded to GitHub's own best practices.

> **Audience.** Written for mixed technical staff — developers plus adjacent technical roles (QA, data, DevOps, technical PMs). It assumes you can open an editor, clone a repo, and read a diff. It does **not** assume you have used an AI coding assistant before.

---

## What you'll be able to do

By the end of the **Mate · Advanced** band you will: choose the right Copilot mode for a task without thinking; steer Copilot with context, custom instructions, and prompt files; review AI-written code as rigorously as human-written code; and stand up a repeatable, customized Copilot workflow your team can adopt.

---

## The 3 × 3 matrix

| | **Mindset** (how to think) | **Toolset** (what to use) | **Skillset** (what to do & automate) |
|---|---|---|---|
| **Beginner** | Author-in-the-loop; what Copilot is *not* for | Install, sign in, inline completions | Accept/reject a suggestion; get one function written and verified |
| **Intermediate** | Trust calibration; verify before you commit | Ask / Edit / Agent modes; #-context; slash commands | Prompt patterns; scope edits; use chat to explain & test |
| **Advanced** | Security, licensing & data governance instincts | Custom instructions, prompt files, MCP, code review | Repo-wide changes; automate a workflow; the coding agent; mentoring |

Work all three columns together, band by band. Detail lives in [01-mindset](01-mindset.md), [02-toolset](02-toolset.md), and [03-skillset](03-skillset.md).

## Prerequisites

- An editor: **VS Code** (best-supported), Visual Studio, or a JetBrains IDE.
