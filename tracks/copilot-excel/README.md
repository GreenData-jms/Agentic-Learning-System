# Track 6 — Copilot in Excel  · *(Scaffold)*

**Family:** Microsoft 365 · **Surface:** Excel (requires a Microsoft 365 Copilot licence) · **Grounded in:** the active workbook + Graph · **Rank:** Mate

## What makes this track distinct

Copilot in Excel works over **structured data in a workbook**: suggesting **formulas**, recommending **chart types**, surfacing **insights and trends**, and helping analyze a table you point it at. Its distinctive discipline is **data shape** — Copilot in Excel is most capable when data is in a proper table with clean headers, and its answers must be checked against the actual numbers. Requires a **Premium** ([Microsoft 365 Copilot](../copilot-chat-premium/)) licence.

> **Distinction to hold:** this is Copilot reasoning over *your rows and columns*. The core Mindset lesson is that a confident formula or insight is still a claim to verify against the data.
