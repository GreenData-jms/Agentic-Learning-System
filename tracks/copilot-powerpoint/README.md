# Track 8 — Copilot in PowerPoint  · *(Scaffold)*

**Family:** Microsoft 365 · **Surface:** PowerPoint (requires a Microsoft 365 Copilot licence) · **Grounded in:** the active deck + Graph · **Rank:** Mate

## What makes this track distinct

Copilot in PowerPoint can **draft a presentation from a prompt or an existing document**, **summarize** a deck, and take **light commanding** actions — adding slides, images, and adjusting content. Its distinctive discipline is **structure and design judgment**: a generated deck is a scaffold, and the human curates narrative, trims filler, and owns the visual result. Requires a **Premium** ([Microsoft 365 Copilot](../copilot-chat-premium/)) licence.

> **Distinction to hold:** Copilot produces a *draft deck fast*; the value you add is editorial — story arc, cutting slides, and design coherence.
