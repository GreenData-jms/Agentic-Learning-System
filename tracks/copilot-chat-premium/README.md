# Track 4 — Copilot Chat: Premium  · *(Scaffold)*

**Family:** Microsoft 365 · **Surface:** Copilot Chat + in-app across Microsoft 365 · **Grounded in:** your work data via Microsoft Graph + web · **Rank:** Mate

## What makes this track distinct

**Microsoft 365 Copilot (Premium)** is the **licensed** tier that adds the one thing Basic lacks: **grounding in your work data through Microsoft Graph** — your files, emails, chats, people, and meetings, always respecting each user's existing permissions. It also unlocks **in-app Copilot** across Word, Excel, PowerPoint, Outlook, and Teams, plus advanced agents (Researcher, Analyst). This track is the hub of the Microsoft 365 family; the app tracks (Word/Excel/PowerPoint/Teams) are its spokes.

> **Distinction to hold:** Premium is defined by "it can see *my* work data." That single capability — and the governance it demands (Purview, Restricted SharePoint Search, oversharing controls) — is the spine of this track.
