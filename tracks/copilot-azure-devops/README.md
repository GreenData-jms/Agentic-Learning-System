# Track 2 — Copilot in Azure DevOps  · *(Scaffold)*

**Family:** GitHub × Azure DevOps · **Surface:** Azure Boards work items, PRs, pipelines · **Grounded in:** work items + linked repo context · **Rank:** Mate

## What makes this track distinct

This is **GitHub Copilot's intelligence brought into the Azure DevOps delivery surface** — not a separate product but an integration. Where the [GitHub Copilot track](../github-copilot/) lives in the editor and is grounded in code, this track lives in **Azure Boards**: drafting and refining **work items**, summarizing and reviewing **pull requests**, and (via Copilot autofix) acting on pipeline findings. Learn this track when your team *plans and tracks* delivery in Azure DevOps rather than GitHub Issues. It builds directly on GitHub Copilot fluency — take that track first.

> **Distinction to hold:** GitHub Copilot answers "how do I write this code?"; Copilot in Azure DevOps answers "how do I plan and shepherd this *work item* to a merged PR?"
