# Track 5 — Copilot Studio  · *(Scaffold)*

**Family:** Power Platform · **Surface:** Copilot Studio maker portal · **Grounded in:** whatever data sources you connect · **Rank:** Mate

## What makes this track distinct

Every other track teaches you to **use** a Copilot. This one teaches you to **build** one. **Microsoft Copilot Studio** is the low-code studio for authoring custom agents — defining topics, connecting knowledge sources and actions, adding generative orchestration, and publishing to channels (Teams, web, and Microsoft 365 Copilot itself). The learner shifts from *operator* to *maker*. Take this track after you are comfortable *using* [Copilot Chat: Premium](../copilot-chat-premium/), so you know what a good agent feels like before you build one.

> **Distinction to hold:** Studio is the only track where the deliverable is an **agent other people will use**, not an answer for yourself. That changes the whole discipline — design, testing, governance, and lifecycle enter the picture.
